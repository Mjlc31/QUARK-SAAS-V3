# Integrations

- **Supabase**: Primary database, authentication, and data storage.
- **Evolution Go API**: Used for WhatsApp integration (`http://localhost:8080`). Handles sending/receiving messages and QR code generation.
- **Google Calendar API**: Used to insert tasks into the team's calendar (via `googleapis`).
- **Google GenAI / OpenAI**: Used for OCR (invoice upload) and potentially conversational AI processing (spinAgent, server.js).
